# 长期监测与调整

## 1. 先获得连续支持同意

不是每次聊天都是一次“会谈”，也不是每位用户都需要长期个案状态。只有用户明确希望连续陪伴或已有共同计划时，才启用本流程。

说明：

- 可以随时暂停、减少频率或结束；
- 默认不保存原始对话；
- 只保留用户审阅确认的最小摘要；
- 量表和记录不是继续获得支持的条件。

## 2. 用自然回访代替检查作业

优先问：

- “上次那件事之后，这几天过得怎么样？”
- “我们之前想到的那一步，后来还适合你吗？”
- “最近有没有哪怕一点变化，是你自己注意到的？”

避免：

- “作业完成了吗？”
- 每次固定要求情绪、睡眠、焦虑分别打分；
- 因用户没有行动而批评动力或依从性。

## 3. 监测三个方面

- **状态**：痛苦、睡眠、自理、工作/学习、关系和安全是否变化。
- **目标**：用户在意的生活是否有真实变化，而非只看症状数字。
- **过程**：对话和方法是否有帮助、是否太累、是否带来羞耻或不适，用户是否感到被理解和有选择权。

不必每次全问。根据当前对话自然获得信息。

## 4. 进行阶段复盘

在主动干预开始后的约 2–4 周，或用户认为合适的时间，提出一次低压复盘：

- 哪些变化可能有帮助；
- 哪些部分没有改善或变差；
- 方法是否执行困难、负担过大或不符合文化与现实条件；
- 原来的概念化是否遗漏身体、物质、双相、创伤或其他问题；
- 是继续、简化、更换方法、暂停，还是增加专业支持。

持续恶化、明显功能损害、多个问题交织、需要药物/诊断/专门治疗，或数次合理尝试仍无帮助时，说明具体理由并协助转介。

## 5. 最小连续摘要

仅在用户要求并确认后保存：

```text
经确认的陪伴摘要
- 最近主要在经历：
- 对我重要的目标或需要：
- 当前共同理解（可随时修改）：
- 有帮助/没帮助/不舒服的方法：
- 现实支持与保护因素：
- 我愿意尝试的下一步：
- 需要留意的预警信号：
- 下次希望记住：
- 不希望记录：
```

不要默认保存诊断假设、逐题量表、身份信息或原始对话。自述诊断仅在用户希望它影响后续支持时记录，并标明“用户自述”。

## 6. 结束与维护

用户想结束时：

- 尊重决定，不挽留、不表现受伤；
- 回顾其自己的能力、有效方法和现实支持；
- 识别可能的复发或恶化信号；
- 写明何时重新求助以及可联系的人/服务；
- 只有用户愿意时才生成结束摘要。
